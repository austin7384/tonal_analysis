INPUTS
------
`nber' (tempfile) — paired article/NBER working paper dataset with LLM readability scores (nber_llm_readability_score, _llm_readability_score), FemRatio, and controls
`author' (tempfile) — author-level dataset with ArticleID, AuthorWeight, and gender/time-to-publication variables; merged to nber by ArticleID

OPERATIONS
----------
- Loads `nber', merges m:m with `author' on ArticleID (keeping matched observations only, no generate), saves result to a new tempfile `nber_author'.

- Constructs a binned time variable `tBin' (tempvar) from t using recode: t=1→1, t=2→2, t=3→3, t=4–5→4, t>5→5. Labels values as "1", "2", "3", "4-5", "6+".

- Runs two OLS `regress` equations with author weights (aweight=AuthorWeight):
    - `nber`: dependent variable nber_llm_readability_score; regressors c.FemRatio##c.tBin, Maxt, MaxT, asinhCiteCount, N, NativeEnglish FE, Journal×Year FE, Editor FE. Stored as `nber`.
    - `reg`: same specification with _llm_readability_score as dependent variable. Stored as `reg`.
    - `suest nber reg` with SEs clustered by Editor. Stored as `suest`.

- Computes five `margins` post-estimation quantities from the suest model, each iterated over all tBin cells (5 cells):
    1. Predicted R_pub − R_draft at FemRatio=1 (women) — direct peer-review impact for fully female-authored papers
    2. Same at FemRatio=0 (men) — direct peer-review impact for fully male-authored papers
    3. Marginal effect of FemRatio on published article score (dydx, reg_mean equation)
    4. Marginal effect of FemRatio on working paper score (dydx, nber_mean equation)
    5. Diff-in-diff: contrast FemRatio=1 vs FemRatio=0 in (R_pub − R_draft), over tBin

- Accumulates margin estimates and SEs into matrices B (5 rows × 5 cols) and SE (5 rows × 5 cols).

- Loops over tBin cells (i=1 to 5). For each cell i: extracts column i from B and SE as row vectors, posts as stored estimate `est_i' using `ereturn_post' with colnames (women, men, reg, nber, diff) and FE indicators.

- Writes `estout` for all 5 stored estimates (est_1–est_5) to a single LaTeX table with varlabels for women/men/diff/nber/reg and section headers ("Predicted R_pub−R_draft" and "Marginal effect of female ratio") inserted via `blist`.

- Calls `create_latex` with tablename "table9llm". Clears all stored estimates.

OUTPUTS
-------
~/tonal_analysis/outputs/tables/tex/Table-10-llm.tex — LaTeX table: 5 columns (one per tBin: t=1,2,3,4-5,6+) × 5 rows (women, men, diff-in-diff, draft, published); shows predicted peer-review impact on LLM readability and marginal effect of female ratio, from suest with author weights and Editor-clustered SEs

## Stata Code Review: `Table-10-llm.do`

### Warnings (likely bugs)
- [WARNING] line 5: `merge m:m ArticleID using \`author'` — `merge m:m` in Stata does not create a Cartesian product; it matches observations in key-order, pairing the i-th master row with the i-th using row for each ArticleID. If `nber` has one row per article and `author` has multiple rows per article (one per author), `merge 1:m` is the correct type. Using `m:m` here silently pairs observations by order-of-appearance rather than properly expanding the data, and Stata emits a warning about `m:m` misuse. The same pattern appears in Figure-6-llm.do and Figure-6-llm-g3.do.

### Notes (worth knowing)
- [NOTE] line 6: `tempfile nber_author; save \`nber_author'` — the tempfile is saved but never reloaded. The rest of the script works on the in-memory dataset. The save is harmless but dead code.
- [NOTE] line 56: Hardcoded `~/tonal_analysis/` prefix in output path. Not portable.
- [NOTE] file-wide: No `version` statement.
- [NOTE] file-wide: `\`nber'` and `\`author'` are tempfile macros defined in the master do-file. Standalone execution would fail.
