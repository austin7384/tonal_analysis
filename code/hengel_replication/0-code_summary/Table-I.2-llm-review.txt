### Warnings (likely bugs)
- [WARNING] lines 33–34: `elist()` group-header rows end with `"\\"`. Estout strips one backslash level, so `\\` in the Stata string produces a single `\` in the `.tex` file. LaTeX requires `\\` to terminate a table row; the generated `.tex` will fail to compile. Should be `\\\\` to produce `\\` in output. Affects both `c.First@1.Female` and `c.Mean@1.Female` elist entries.
