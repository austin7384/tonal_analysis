INPUTS
------
`author' (tempfile) — author-level panel dataset with LLM group composite scores (llm_g*) and gender indicators, used by the `author_level` program for dynamic panel estimation

OPERATIONS
----------
- Redefines program `author_level_table` with required `type(string)` option. The program:
    - Calls `estout` on stored estimates named `xtabond_*` to write a LaTeX regression table for the given gender-definition variant.
    - Displays stats rows: N, Hansen test p-value, Sargan test p-value, AR(1) test, AR(2) test, editor FE, blind review, journal FE, Nj, institution FE, quality controls, native speaker.
    - Applies `varlabels` for: Female (β₁), Male (β₁+β₂), Interaction (β₂), and lagged score (β₀).
    - Calls `create_latex` on the output file using tablename "table4llm" and the supplied type.

- Runs `author_level` (defined elsewhere, reused from Table-F.2.do context) followed by `author_level_table` for six gender-definition variants:
    1. FemRatio — continuous female authorship ratio
    2. Fem100 — exclusively female-authored papers
    3. FemSolo — solo female-authored papers
    4. Fem1 — at least one female author
    5. Fem50 — majority female-authored
    6. FemSenior — senior (last) author is female

- For each variant, `author_level` loads `author', runs dynamic panel (Arellano-Bond / xtabond2) regressions of LLM group composites on the gender indicator with controls, and stores estimates as `xtabond_*`. `author_level_table` then writes those estimates to the corresponding `.tex` file.

OUTPUTS

~/tonal_analysis/outputs/tables/tex/Table-F.2-llm-Fem100.tex — same specification with Fem100 gender indicator
