INPUTS
------
`nber_fe' (tempfile) — paired article/NBER working paper dataset for paired-difference (nber_fe) regressions, main sample
`nber' (tempfile) — paired article/NBER dataset for FGLS-style suest regressions, main sample
`nber_fe_jel' (tempfile) — paired dataset restricted to articles with JEL codes, for nber_fe with JEL fixed effects
`nber_jel' (tempfile) — paired dataset restricted to articles with JEL codes, for suest regressions with JEL fixed effects

OPERATIONS
----------
- Redefines program `nber_fgls` (eclass) — accepts a gender varname, an optional `if` condition, a `using` dataset path, a `stats(string)` list of LLM group composite criteria, `colnames`, and an optional `jel` flag.
    - For FemRatio and FemSenior: treats gender as continuous (c.varlist). For all others: binary (1.varlist).
    - Loops over each criterion in `stats`. For each criterion:
        - Renames `nber_<crit>_score` → `nber_score` to allow a uniform regressor name across iterations.
        - Runs OLS (col 1 control) via `reghdfe`: dependent var `_<crit>_score` on nber_score + gender×Blind interaction + N, Maxt, MaxT, asinhCiteCount, NativeEnglish FE, Type_* + absorbed Journal×Year FE, Editor FE, optional JEL1_* FE; SEs clustered by Editor. Stores as `ols_<crit>`.
        - Extracts gender coefficient, Blind×gender coefficient, nber_score coefficient.
        - Renames `nber_score` back to `nber_<crit>_score`.
        - Runs FGLS pair via OLS `regress` (not reghdfe) for nber (NBER paper) and reg (published paper), then `suest nber reg` with SEs clustered by Year.
        - Applies `lincom` to compute published–NBER difference and Blind×gender published–NBER difference from suest.
        - Accumulates 9 rows of estimates per criterion into matrices B and SE: (1) nber_score coeff from OLS, (2) gender coeff from OLS, (3) Blind×gender from OLS, (4) NBER gender from suest, (5) NBER Blind×gender from suest, (6) pub gender from suest, (7) pub Blind×gender from suest, (8) difference, (9) Blind×gender difference.
    - Posts 9 stored estimates using `ereturn_post`: reg_nber, reg, reg_blind, su_wp, su_blind_wp, su_pub, su_blind_pub, su_diff, su_blind_diff.
    - Note: `estimates restore ols*_llm_g1` is called to recover N and df_r from the first criterion's OLS for rows 1–3; `estimates restore nber/reg/suest` for rows 4–9.

- Redefines program `nber_table` — accepts `type(string)` and optional `jel` flag. Writes `estout` for all 11 stored estimate sets (reg_nber, reg, reg_blind, fe, fe_blind, su_wp, su_blind_wp, su_pub, su_blind_pub, su_diff, su_blind_diff) to the type-specific `.tex` file; calls `create_latex` with tablename "table6llm".

- Runs `nber_fe` (defined elsewhere) + `nber_fgls` + `nber_table` for 9 variants:
    1. FemRatio — full sample
    2. Fem100 — exclusively female-authored
    3. FemSolo — solo female-authored
    4. FemSenior — senior (last) author is female
    5. FemJunior — FemSenior restricted to Maxt<=3
    6. Fem1 — at least one female author
    7. Fem50 — majority female-authored
    8. wordlimit — FemRatio restricted to BelowAbstractLen==1
    9. jel — FemRatio with JEL controls, using `nber_fe_jel' and `nber_jel'

- Each variant calls `estimates clear` before running to reset stored estimates.

## Stata Code Review: `Table-5-llm.do`

### Warnings (likely bugs)
- [WARNING] lines 30/44: Inside the `foreach stat` loop, `rename nber_\`stat'_score nber_score` (line 30) and `rename nber_score nber_\`stat'_score` (line 44) are not protected. If any estimation command between them errors and aborts the iteration, the variable is left permanently as `nber_score`. Every subsequent loop iteration will then fail at line 30 because `nber_\`stat'_score` no longer exists (it was already renamed). Wrap in `capture` with explicit error checking, or use `tempvar`.

- [WARNING] lines 138/144/150/156/162/168/174/180/186: `nber_fe` is called but not defined in this file. The comment on line 4 says only `nber_fgls` is redefined here; `nber_fe` is expected to persist from Table-5.do. If Table-5.do is commented out in hengel_master.do, all nine `nber_fe` calls will fail with "unrecognized command." Unlike Table-5-llm-individual.do, which redefines `nber_fe` at the top for standalone use, this file does not.

### Notes (worth knowing)
- [NOTE] line 128: Hardcoded `~/tonal_analysis/` prefix in output path. Not portable.
- [NOTE] lines 69/74/80/86/92/98/104/110/116: `estimates restore ols*_llm_g1` uses a wildcard. Stata's `estimates restore` supports `*` as a wildcard; this matches `ols_llm_g1`. If the stats list passed to `nber_fgls` does not include `llm_g1` as the first element, this hardcoded reference will restore the wrong estimate (or fail). The `firststats()` fix in Table-5-llm-individual.do addresses this; this file retains the fragile hardcoded form.
- [NOTE] file-wide: No `version` statement.
