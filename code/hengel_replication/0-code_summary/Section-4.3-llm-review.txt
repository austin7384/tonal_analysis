- [NOTE] line 116: `psmatch2 Female if T>2` — Stata treats missing `T` as larger than any real number, so observations with missing `T` satisfy `T>2` and would be passed to `psmatch2`. If `T` is never missing in this dataset, this is harmless.

If any group count equals zero (no discriminatory pairs detected for a given composite), the matrix is singular and Stata will error with `r(506)`. Same risk at line 386 for `inv(diag(\`bm1'))` if any conditional male mean is exactly zero.
