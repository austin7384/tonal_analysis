INPUTS
------
`article' (tempfile) — article-level dataset with LLM readability scores (_llm_readability_score) and FemRatio0 (continuous female authorship ratio)

OPERATIONS
----------
- Loads the article-level tempfile.

- Recodes FemRatio0 into a binned variable FemBin with four discrete values: 0 (all male), 0.25 (10–40% female), 0.5 (exactly 50% female), 0.75 (60–80% female), 1 (all female). Generated as a new variable.

- Runs simple OLS `regress` of _llm_readability_score on FemBin to obtain a slope coefficient (β) and its SE. These are stored as local macros (beta_text, se_text) formatted to 2 decimal places for annotation purposes.

- Produces a `binscatter` plot of _llm_readability_score against FemBin:
    - Uses discrete option (treats FemBin as categorical bins, plots bin means)
    - Overlays a linear fit line
    - Color scheme: pfblue for both scatter and line
    - X-axis labeled at 0.25, 0.5, 0.75, 1 with title "Ratio of female authors"
    - Y-axis titled "LLM Readability"
    - Annotates the plot with the OLS slope (β) and SE in gray text at position (5.5, 0.8)
    - Aspect ratio 0.4; uses publishing-female scheme and Avenir-Light font face

- Exports the figure as a PDF.

OUTPUTS
-------
~/tonal_analysis/outputs/figures/Figure-1-llm.pdf — Binscatter plot of LLM readability score against binned female authorship ratio, with OLS linear fit and β annotation
